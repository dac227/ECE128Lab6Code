# ECE128Lab6Code

This repository contains Verilog code for the design three different FSM of a debouncer, Moore type code reader, and Mealy type code reader. This is for ECE 128 Lab 6. It contains testbenchs and logical equations to change states within each system.

Instructions:

1. Create project in Vivaldo using correct FPGA selected

2. Move FSM code into source file. Can also swap these out each testing case.

3. Assign inputs to switches on FPGA and outputs to LEDs usings provided file

4. Add the test bench scripts as constraints in Vivado

5. Run Simulation to check wave form (Test bench should show appropriate addition in hexadecimal)

6. Run synthesis and check resulting gate level results

7. Create bit stream

8. Program FPGA

9. Test FPGA if all test cases work
